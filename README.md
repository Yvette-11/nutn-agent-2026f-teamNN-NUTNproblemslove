題目2：
問題：大學生除了課業之外，常常還需要同時兼顧打工、社團、活動與私人行程，因此容易出現時間分配不均、讀書計畫難以維持，以及臨時行程變動後需要重新安排的問題。傳統課表只能呈現固定行程，無法根據學生的目標、任務優先順序與實際進度動態調整。系統希望透過 AI Agent，自動協助學生進行時間規劃、任務安排與後續調整，降低學生自行規劃的成本。

使用者：主要使用者為需要同時兼顧多項活動的大學生，例如同時有課業、打工、社團、報告或考試的學生。

User Story：身為一名可能同時需要兼顧課業、打工與社團的大學生，我希望能透過 AI Agent 協助規劃讀書時間與每日行程，合理分配可使用的時間，降低自行安排課表與調整計畫的成本，讓我能更專注在實際學習上。

Agent 必要性：此問題並非只需要一次性的課表產生，而是需要持續根據學生目前的狀態進行判斷與調整。Agent 必須能夠蒐集課程與行程資訊、分析任務的重要性與截止時間、自主安排讀書計畫、追蹤實際完成進度，並在出現臨時行程、任務延遲或截止日期變更時重新規劃後續時間。

因此系統需要形成持續性的循環：
蒐集資訊 → 分析任務 → 規劃時間 → 執行／追蹤 → 偵測變化 → 自動重新規劃
